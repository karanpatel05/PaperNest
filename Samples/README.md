# Synthetic samples

These documents are generated by `scripts/swift.sh run papernest-samples Samples` from `Tests/Support/SyntheticDocuments.swift`. They contain no real personal data, so they're safe for demos, screenshots and manual testing.

Regenerated images are byte-identical. Regenerated PDFs differ because each embeds its creation date and document ID.

Each file has an orientation marker, a solid square at the top-left of its upright content, so rotation mistakes are easy to see.

| File | Exercises |
|---|---|
| `multilingual-letter.pdf` | 3 vector text pages in English, French and Spanish (accents, `¿`, currency formats). Text should stay selectable after export. |
| `rotated-page.pdf` | A page with `/Rotate 90`. It should import upright and landscape. |
| `password-protected.pdf` | Password prompt. The password is `sample`. |
| `receipt-portrait-exif6.jpg` | Pixels stored sideways with EXIF orientation 6. It should show upright and portrait. |
| `whiteboard-300dpi.png` | 1275×1650 px with 300 dpi metadata. It should import as a 4.25×5.5 in page, not the 11 in fallback. |
| `transparent-ink.png` | Transparent background with dark ink. JPEG export should show the ink on white. |
