## Intentional differences and remaining work

The complete requested feature set is **not finished**. This is the implemented core redesign, with these explicit boundaries:

1. **Capture visual parity:** Apple’s documented [VNDocumentCameraViewController API](https://developer.apple.com/documentation/visionkit/vndocumentcameraviewcontroller) presents the scanning UI and returns page images; it exposes delegation and availability, not a configurable shutter/overlay/mode rail. The implementation therefore keeps that capture UI intact. A bespoke AVFoundation/Vision camera would need device-verified detection stability, capture timing, orientation, flash, interruptions and permissions. It is not implemented merely for mockup parity. Book dewarping, ID layout and whiteboard-specific processing are not exposed as identical fake modes.
2. **Save flow:** capture is committed immediately, then reviewed in the existing autosaving editor. Rename is in the title menu; folder movement is in the library/Home menus. There is no separate unsaved scan staging workspace, scan-specific Save-to-folder sheet, per-page duplicate operation, or exact "Scan Edit" title. Early durable import protects captures on interruption. Existing crop operates on PageTransform bounds; custom editable perspective handles after capture remain a backend/rendering follow-up.
3. **Notebook rendering:** the durable representation currently supports pen/highlighter strokes and blank/lined/grid templates. Fountain/ballpoint/pencil fidelity, dotted/Cornell templates and landscape formats need matching store/render/export work before exposure. Pixel eraser size/type controls and object copy/paste/rotation are not added. Existing lasso, move, resize, editable text and images remain; this does not claim complete Goodnotes parity.
4. **Cloud/shared/Vault:** no sync/account/collaboration provider exists in this checkout. Secure Vault is a separate planned project (`superpowers/plans/2026-11-04-secure-vault.md`), not implemented here. Projects/Study show only when supported by actual user-created folders; Home displays up to two existing folders alongside Notes/Documents.
5. **Advanced Notes priority:** next, close device handwriting/save/background and accessibility gates; then durable templates/brush fidelity and object operations; then handwriting-specific recognition/conversion/search evaluation. Audio-linked notes require recording/timestamp persistence; AI summaries/flashcards need explicit provider/privacy/offline and data-model decisions. OCR text extraction and searchable PDF text-layer export already exist; they are not described as handwriting-to-text guarantees.
6. **Platform validation:** unit and build results do not establish camera/Pencil behavior, VoiceOver usability, every localization layout or Mac interaction. See TEST_MATRIX for exact checks run.
